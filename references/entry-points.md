# 退款入口定位速查表（实测 2026-10-12，桌面网页端）

> 页面随时可能改版，执行时以实时页面为准；定位失败走 SKILL.md 的质检上报流程。

## 关键 URL

| 用途 | URL |
|---|---|
| 官网首页（检查登录态） | `https://www.coze.cn/` |
| 套餐管理（退款入口所在页） | `https://www.coze.cn/subscription/manage` |

## 页面结构（套餐管理页）

- 顶部页签：`套餐订阅` / `增购积分` / `云盘扩容包` → 退款在「套餐订阅」页签下
- 「当前套餐」区：套餐名 + 状态徽标（生效中/订购中）+ 到期日文案（如"套餐将于 2027.08.16 到期"）+ 自动续费状态（"自动续费已关闭"）
- 「支付记录」表格列：订阅套餐 / 订阅类型 / 价格（元）/ 购买时间 / 订单编号 / 支付方式 / **操作**
- 目标订单行的「操作」列按钮：「申请退款」（退款提交后变为「退款处理中」）

## 确认弹窗（点「申请退款」后）

- 标题：「确认申请退款？」
- 字段：退款商品 / 订单编号 / 支付方式 / 预计退款金额
- 条款行（实测文案，执行时以实时为准）：「退款金额按订单剩余价值计算。提交后将收回对应剩余权益，申请提交后不可撤销。」
- 按钮：「取消」 / 「确认退款」（最终提交按钮，需用户明确确认后才可点）

## 成功提示（点「确认退款」后）

- 实测文案：「退款申请已提交，预计 2-3 个工作日原路到账，请注意查收。申请退款金额 ¥869.00」→ 点「完成」关闭

## 登录页

- 路径：官网右上角「登录」→ 优先「抖音扫码登录」（二维码展示给用户扫）
- 备选：「手机号 + 短信验证码」（手机号问用户要；验证码用户亲口给；agent 不读短信）
